# BSVC Link Bypasser

Automated `bc.vc` link bypasser in Python, built by analyzing a browser extension's API.

## Requirements

Install the required dependencies:

```bash
pip install requests pycryptodome urllib3
```

##  How It Works

This script reconstructs the bypass mechanism of a browser extension into a standalone Python tool without requiring browser automation.

* **API Discovery:** Identified a backend API used by the extension, authenticating via a custom `X-Meow` header.
* **Payload Decryption:** The API dynamically returns an encrypted access key and a list of accepted domains.
* **Key Extraction:** The AES-GCM decryption key is generated by hashing a PHP-serialized array of the accepted domains using SHA-256.
* **Implementation:** The script mimics this exact flow to generate the key, decrypt the payload, and retrieve the final destination URL.
